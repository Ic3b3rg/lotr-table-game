**Implementation decision.** Port the complete ordered selection and search below, then persist the realized four-section map and encounter assignments. A seed plus the 44 base faces is insufficient: the installed standard bucket shuffles **120** entries, custom `100A` shadows standard `100A` by numeric model identity, failed searches retain advanced randomness, retries retain encounter pools, and a five-second rule can change section backtracking. Preserve these behaviors explicitly; a simpler generator must receive a different algorithm identity. [A1319:038a–0527; A0e9c:0000–0111; A131c–1321; A3c93:0b10–0c2b; A1310:0017–0048.]

**Tile eligibility, trait assignment and intra-section placement.** Explicit start/required retrieval does not pass through `CanUseTile`. Generic trait/random seeding scans the shuffled standard bucket from index0 every call. It checks other sections' reservations and current seed ownership, removes the selected face through auto bucket routing, then checks: no TileModel set bit outside AllowedTileSets; no opposite face already in any AvailableTiles; candidate space count plus cached SpacesFromAvailableTiles ≤ max+extra; and `WouldSequenceExist(currentSequence,candidateHash)==false`. A rejected removed tile is returned. There is no new RNG draw for this scan. A trait candidate must have a space carrying a required trait whose current available count is below that requirement's count; requirements are considered in serialized order. [A1346:0017–003e; A1347:000e–0032; A134d:000e–0118; A134e:000b–009f; A1351:0000–00a0; A1323–1324.]

The overall trait satisfaction test is stronger than separate bit counts: expand each required count into one slot, flatten nonzero trait masks from available tiles/spaces in their source order, and find a one-to-one matching of required slots to distinct space indices. For each requirement, scan eligible space indices, reserve the first full bit-mask match, backtrack to the prior reserved index+1 when needed. One multi-trait casella cannot satisfy two slots simultaneously. The tile-seeding heuristic still uses the simpler per-trait counts above; preserve both behaviors. SpacesFromAvailableTiles is updated on add/remove during seeding, but `GetFromAvailableTiles` during layout only removes the list entry. **Coordinate frames, edges and exact section-vs-map attachment.** Cube directions0..5 are `(1,−1,0),(0,−1,1),(−1,0,1),(−1,1,0),(0,1,−1),(1,0,−1)`. Positive rotation applies `(x,y,z)→(−z,−x,−y)`; inverse applies `(−y,−z,−x)`; directions rotate modulo6 and opposite adds3. Preserve TileCoords as intrinsic immutable coordinates, integer GlobalCoords as the evolving occupancy coordinates, tile LocalRotations, section LocalRotations, and source display transforms separately. `Tile.GetRotationIntervals(true)` returns tile rotation; `false` returns tile+section rotation. [A0a10:0000–0060; A0a1c:001d–00a4; A0a0a:0000–002d; A0a0b; A0e87:0000–002d.]
